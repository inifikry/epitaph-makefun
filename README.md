# Famous Last Words: The Funniest Epitaph

A single one-line tombstone epitaph, written by `main.py` to `/output/entry.txt`:

> I asked for one last wish. They gave me this rock.

## Run

```sh
python3 main.py
```

The program is deterministic: it writes the same fixed line on every run,
with no network access and no input files. The output is 50 characters of
UTF-8 text, within the 1–150 character gate.
